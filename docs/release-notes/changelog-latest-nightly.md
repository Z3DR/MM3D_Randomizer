# Latest Nightly Changes

## Features

### Custom Tunic Colors
- **Custom Tunic Colors.** New cosmetic option with a separate color for each form: **Human**, **Deku**, **Goron** and **Zora** (Fierce Deity keeps his own look). Each form can pick from 31 named colors (Kokiri Green, Goron Red, Zora Blue, Majora Purple, NES Green, ...), a random named color, a fully random color, or a custom one. Deku, Goron and Zora can also follow the Human tunic.
- **Color picker.** Choosing *Custom* opens a color picker you can drive with the Circle Pad, D-pad Up/Down or the touch screen. **Y** picks a random color.
- **Change it in game.** The in-game Options menu has a new **Tunic Colors** page to change each form's color during a playthrough.


## Bug Fixes

### Item placement and logic
- **Kotake's Mushroom Sale gives a proper item.** Trading a Mushroom to Kotake in the Potion Shop now gives the item shown on the shop's third shelf, and the generator treats it as a shop check. (thanks [Gonzalo](https://github.com/GonzaloJMora)!)
- **Logic now knows about duplicate checks while placing items.** Checks that exist in more than one place (the three postboxes, the Keaton Quiz, Tingle's maps, spring Goron Village, the cleared swamp, etc) get their item copied as soon as it's placed, so logic can count whichever copy you reach first.

### Fierce Deity
- Fierce Deity no longer attacks with his sword constantly when receiving a sword pickup.

## Other Changes

- The spoiler log now lists an alternate copy of a check (spring Goron Village, the cleared swamp, etc) when it holds a WOTH item on the playthrough, so the route through it is visible.
