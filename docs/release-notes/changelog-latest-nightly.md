# Latest Nightly Changes

## Features:
Feat: Extra Ice Trap setting added implementing the following:

Three additional ice traps:
- Shock trap: Shocks you in place and takes 1-3 hearts of damage.
- Fire trap: Throws you and sets you on fire
- Reverse control trap: Reverse your controls

These are randomly selected at run time, so even on cycle reset you could get a different ice trap.

Feat: Camera speed modifier setting added to set the in game camera speed: 
from 0.25x - 5.0x speed. This is also changeable in game 

## Bug Fixes
Fix: Adjusted the exit from Beneath the Well Mirror Shield Room to resolve issue where Mirror Shield could be expected to enter the the room to open the chest from the Ikana Castle side but that is not possible since entering from that side requires Light Arrows.  
Fix: logic helper HasBombchu was not being set properly.
